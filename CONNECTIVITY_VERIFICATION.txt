TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

Issue: "Connection Timeout" or "Failed to connect"
  Cause:     Backend may be cold-starting
  Solution:  Wait 30-60 seconds and try again
  Permanent: Render.com paid tier keeps servers warm

Issue: "API Key Invalid" or "Unauthorized"
  Cause:     API_SECRET_KEY mismatch
  Solution:  Check lib/utiles/api_url.dart matches backend .env
  Current:   Both set to "sochio-api-secret-2024" ✅

Issue: "JWT Token Invalid"
  Cause:     Token expired or corrupted
  Solution:  Log out and log in again
  New token: Generated with JWT_SECRET "sochio-jwt-secret-2024"

Issue: "No Internet Connection"
  Cause:     Device/network issue
  Solution:  Check internet connection
  App check: connectivity_plus package in pubspec.yaml ✅

Issue: "Admin panel shows blank"
  Cause:     Backend API call failed
  Solution:  Open browser console (F12), check Network tab
  Verify:    REACT_APP_API_URL in admin .env ✅
